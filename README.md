# ARDIN — Architecture & Design d'intérieur

Site vitrine d'un cabinet d'architecture de luxe (projet de fin de formation Datasuits — « 48H Chrono »).

- **Stack** : HTML5 sémantique, CSS3 (variables, grid, clamp), JavaScript vanilla (IntersectionObserver)
- **Design** : maquette Figma desktop + mobile, palette noir / anthracite / or / beige / ivoire
- **Typographies** : Cormorant Garamond (titres) + Jost (texte)
- **Accessibilité** : textes alternatifs, labels de formulaire, `prefers-reduced-motion`, navigation clavier
- **Visuels** : Unsplash (licence libre)
